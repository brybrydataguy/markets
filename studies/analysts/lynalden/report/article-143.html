143-C05 · explanation · source blocks 28

Volatility sellers face tails.

Right
HorizonNot specified
ConditionsNot specified
Author modalityasserted
Deductive reasoning, not an empirical outcome test

Seller payoff=P-max(S-K, 0). If S exceeds K+P, the loss exceeds collected premium; losses grow with S.

Assumptions: Unhedged short call; Fixed strike K and premium P; Underlying terminal price S

Short-option payoffs are asymmetric: collected premium is finite while adverse underlying moves can create larger liabilities. Free money is misleading shorthand, not actual risklessness.

Deductive reasoning, not an empirical outcome test

Two disconnected recipients can receive identical note copies and each see the same locally valid signature. Local signature verification cannot distinguish first spend; online reconciliation is necessary.
